# جسی — مدیریت مالی شخصی

مدیریت حساب‌ها، بدهی‌ها، اقساط، پیامک بانکی، نمودارها، بودجه‌ها و بانک اهداف.

## نسخه‌های رسمی

شناسه برنامه: `ir.jessi.finance`؛ نسخه‌های رسمی با امضای یکسان منتشر می‌شوند تا بدون حذف برنامه، قابل ارتقا باشند.
با هر تغییر در `main`، GitHub Actions نسخه را می‌سازد و تست می‌کند، ولی **فقط پس از تأیید امضای معتبر و نصب روی نسخه قبلی** فایل رسمی را منتشر می‌کند.

[دریافت آخرین نسخه‌های رسمی جسی](https://github.com/pooya220/jessie/releases)

## نگهداری امن امضا

امضای ثابت یا با بلوک امضای از پیش تولیدشده برای همان نسخه (`signing/vX.Y.Z.sigblock.b64`)، یا با کلید اصلی داخل GitHub Actions Secret با نام `JESSI_SIGNING_BUNDLE` انجام می‌شود. قالب این Secret یک JSON خصوصی با کلیدهای `keystore_b64`، `store_password`، `key_alias` و `key_password` است.

**کلید خصوصی و رمز آن را هرگز داخل ریپوی عمومی commit نکنید.** اگر امضای معتبر در دسترس نباشد، ساخت نسخه رسمی به عمد با خطا متوقف می‌شود؛ یک APK با امضای متفاوت نمی‌تواند جایگزین امن نسخه قبلی شود.
