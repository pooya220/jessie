# جسی — مدیریت مالی شخصی

مدیریت حساب‌ها، بدهی‌ها، اقساط، پیامک بانکی، نمودارها و دوره‌های مالی.

## روال ساده انتشار

با هر تغییر در شاخه main، GitHub Actions برنامه را می‌سازد و تست می‌کند.
برای هر شماره نسخه، یک فایل APK از بخش Releases قابل دریافت است:
https://github.com/pooya220/jessie/releases

شناسه اپلیکیشن اصلی: `ir.jessi.finance` (بدون Preview).

**توجه:** این روش ساده از Debug APK استفاده می‌کند. امضای Debug بین اجراهای GitHub ممکن است فرق کند و نصب مستقیم روی نسخه قبلی خطای Conflict بدهد.
اگر داده مالی داخل برنامه قدیمی داری، بدون انتقال امن اطلاعات آن را حذف نکن.
برای آپدیت درجا و تضمین‌شده، در آینده به امضای ثابت و خصوصی نیاز است.
