# جسی — مدیریت مالی شخصی

اپلیکیشن آفلاین مدیریت حساب‌ها، تراکنش‌ها، هزینه‌ها، بدهی‌ها و اقساط، دوره‌های مالی و بررسی پیامک‌های بانکی.

## فقط یک نسخه اصلی

- شناسه دائمی اندروید: `ir.jessi.finance`
- خروجی رسمی: `Jessi-vX.Y.Z.apk` در [GitHub Releases](https://github.com/pooya220/jessie/releases)
- انتشار نسخه‌های **Release امضاشده**، بدون APKهای عمومی Debug/Preview/Beta.
- هر نسخه رسمی باید با همان کلید امضا ساخته شود و `versionCode` بزرگ‌تر داشته باشد. در این صورت بدون حذف برنامه نصب می‌شود و داده‌های داخلی حفظ می‌شوند.
- تغییرات ساختار پایگاه داده از طریق Room Migration صورت می‌گیرد؛ دوره مالی داده‌های قبلی را پاک نمی‌کند.

### پیکربندی یک‌باره امضای دائمی

1. فایل خصوصی `Jessi-Signing-Secret.txt` را از بسته پشتیبان امضا باز کنید.
2. در [Repository Actions Secrets](https://github.com/pooya220/jessie/settings/secrets/actions) یک Repository secret به نام `JESSI_SIGNING_BUNDLE` ایجاد کنید.
3. **تمام محتوای** فایل JSON را به عنوان مقدار Secret وارد کرده و ذخیره کنید.
4. فایل `Jessi-Release-Signing.p12` و نسخه پشتیبان را خصوصی، ایمن و خارج از GitHub نگهداری کنید.
5. Workflow `Jessie Official Android Release` را از Actions دوباره اجرا کنید. بعد از تست و ساخت، APK در GitHub Releases قرار می‌گیرد.

**کلید خصوصی نباید هرگز در ریپوی Public یا پیام‌ها منتشر شود.**
اثر انگشت عمومی گواهی امضای رسمی (SHA-256):
`0C:8B:48:68:39:4B:2B:1A:5E:8E:3C:29:C9:5B:9E:45:56:BF:BC:FA:4A:19:66:F4:26:0A:88:0C:B8:FD:B6:D5`

### نصب‌های Debug قدیمی

نسخه‌های قبلی با کلید Debug موقت امضا شده‌اند و **با نسخه رسمی جدید قابل آپدیت مستقیم نیستند**. اگر اطلاعات مالی در نسخه قدیمی ثبت کرده‌اید، **آن را پاک نکنید** تا اطلاعات لازم به صورت ایمن استخراج یا دوباره ثبت شود. همچنین نسخه Preview شناسه دیگری دارد و داده‌هایش جداست.

بعد از نصب اولین نسخه رسمی، آپدیت‌های رسمی جدید روی همان برنامه نصب می‌شوند.
